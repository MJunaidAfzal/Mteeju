Outreach ab sirf WhatsApp se chalta hai. Email wala system poori tarah nikal diya gaya hai —
na Gmail, na app password, na koi khud-ba-khud jane wali email.

Aap ko kya karna hai
1. Database — Supabase → SQL Editor → New query → 20261012000000_outreach.sql paste → Run
   (Agar pehle chala chuke hain to dobara chalane ki zaroorat nahi — purani tables waisi hi chalti hain.)

2. Leads — Leads page → list banayen → Enrich (phone number zaroori hai, email ki ab zaroorat nahi)

3. Campaign — Outreach → New campaign
   - naam, kaun si leads, roz kitne messages, kin ghanton mein, time zone
   - har step ka sirf din aur message (sab WhatsApp)
   - message ke andar {{name}} {{category}} {{city}} {{rating}} {{reviews}}
   - sign-off har message ke aakhir mein khud lag jata hai
   - Save and start

4. Bhejna — Outreach page par "WhatsApp — X ready to send" list aati hai
   - Open WhatsApp → chat khulti hai, message pehle se likha hua → aap send dabate hain
   - wapas aa kar Mark sent (ya Skip)
   - us computer par web.whatsapp.com par apne number se logged-in rehna zaroori hai

Kya khud ba khud hota hai
- Messages apne din aur waqt par khud list mein aate hain
- Roz ki had (daily cap) aur bhejne ke ghante khud lagte hain — had poori hone par list ruk jati hai
- Jis lead ko Replied / Won / Lost / Unsubscribed mark kar dein, us ke baqi messages queue mein nahi aate
- Sab messages nikal jane par campaign khud Finished ho jata hai

Ehtiyat
- Roz 30-50 naye chats se zyada nahi, chahe manual hi hon — warna WhatsApp number block kar deta hai
- Jawab aane par lead ko foran Replied mark karen
