Sab kuch ban gaya aur test ho gaya. Yeh raha mukammal khulasa.

Pehle ek zaroori baat — password mujhe na bhejen
Mujhe aap ka Gmail password ya app password kabhi nahi chahiye, aur chat mein bhejna theek nahi. Aap khud Supabase ke Secrets mein daalenge — code use wahan se uthata hai, kisi file mein likha nahi jata. WhatsApp number bhi mujhe nahi chahiye: one-click queue aap ke computer par jo WhatsApp logged-in hai, usi se bhejta hai.

Aur ek wazahat: asli Gmail password kaam nahi karega — Google cold SMTP ke liye sirf App Password qabool karta hai.

Aap ko kya karna hai (kul ~10 minute)
1. Database — Supabase → SQL Editor → New query → 20261012000000_outreach.sql paste → Run

2. Function — Edge Functions → Deploy a new function → naam outreach-run → index.ts ka poora code paste → Deploy
(maine abhi is mein test-email wala hissa add kiya hai, isi waqt wali file lena)

3. Gmail

Jis Gmail se bhejna hai us mein login → myaccount.google.com/security → 2-Step Verification on
myaccount.google.com/apppasswords → naam "Teeju" → Create → 16 harf copy (spaces hata dein)
Supabase → Edge Functions → Secrets → do secrets banayen: GMAIL_USER = poora email · GMAIL_APP_PASSWORD = wo 16 harf
4. Check karen — portal → Outreach → upar Email sender card → apni email daal kar Send test dabayen.
Sabz paighaam = Gmail jud gaya. Laal paighaam = mujhe wo laal text bata dein, main theek kar dunga.

5. WhatsApp — kuch set nahi karna. Bas us computer par web.whatsapp.com par apne number se logged-in rahen.

6. Pehli campaign

Leads page → aisi list banayen jin ki website ho (Lead Finder mein "Has website" filter) → Enrich
Outreach → New campaign → naam, kitne roz, waqt, aap ka naam aur sign-off
Message ke andar {{name}} {{category}} {{city}} aur {{opening}} (yeh line AI har business ke liye alag likhega)
Save and start → email khud jayegi, WhatsApp wale messages upar queue mein aa jayenge
7. Cron (baad mein bhi chalega) — Integrations → Cron → job 0 * * * * → outreach-run. Is ke baghair bhi sab chalta hai, bas aap "Send due email now" khud dabayenge.

Shuru mein ehtiyat
Pehle hafte 20–30 email roz, phir barhayen — warna naya Gmail spam mein chala jata hai
WhatsApp par bhi roz 30–50 naye chats se zyada nahi, chahe manual hi ho
Jawab aane par lead ko Replied mark karen → us ke baqi saare messages khud cancel
